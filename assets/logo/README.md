# pocket-audit logo

| File | Use |
|---|---|
| `pocket-audit-lockup.svg` / `.png` | Main logo with the wordmark (README header, website, slides) |
| `pocket-audit-lockup-dark.svg` | The same, with light lettering, for dark backgrounds |
| `pocket-audit-mark.svg` / `.png` | The mark alone |
| `pocket-audit-icon.svg`, `-32.png`, `-180.png`, `-512.png` | Small icon: favicon (32), touch icon (180), avatar (512) |
| `pocket-audit-lockup-alt.svg` / `.png` | Alternative wordmark with the icon |
| `social-preview.png` | 1280 × 640 card for the repository's social preview |

**What the mark shows:**
- **Main mark:** learned pockets lying on a model-error surface. The flagged pocket sits in a dip, and the pin with a person marks *where* and *for whom*.
- **Icon:** a forest branching into pockets, with two people compared inside one of them.
- **Colours:** they are illustrative and do not encode any group.
